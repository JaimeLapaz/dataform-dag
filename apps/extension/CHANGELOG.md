# Changelog

All notable changes to Dataform DAG Explorer will be documented here.

## 0.1.0

Initial Marketplace release.

### Added

- Parsed and Compiled graph modes.
- Local Dataform compilation using `dataform compile --json`.
- Inline Compiled SQL preview.
- Full and incremental SQL previews.
- `pre_operations` and `post_operations` support.
- Multiple operation queries.
- Compilation cache and background warm-up.
- Protection against concurrent compilations.
- Persistent multi-tag filtering.
- One-hop dependency Context view.
- Node search and graph navigation.
- Graph diagnostics for unresolved dependencies and duplicate IDs.
- VS Code light and dark theme integration.
- Live graph updates.
- Activity Bar entry with quick access to the graph.
